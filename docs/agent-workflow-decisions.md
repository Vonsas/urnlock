## 5. 리뷰 반복 횟수 (2026-10-27 추가)

결정: pr-reviewer 심각도를 수정 · 권장 · 참고 로 부르고, 수정 · 권장이 0 이 될 때까지 리뷰 → 고침 → 재리뷰를 반복한다.
3차 리뷰까지는 묻지 않고 이어서 하고, 3차 뒤에도 남으면 재리뷰 한 번마다 사용자에게 묻는다. 참고는 세지 않는다.
차수는 PR 리뷰 코멘트 머리의 'N차 리뷰' 로 센다 (`.claude/agents/pr-reviewer.md` '리뷰 반복 규칙').
